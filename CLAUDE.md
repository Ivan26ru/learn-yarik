## Запуск

Сборки, линтеров и тестов нет: каждый `.php`/`.html` — отдельная страница.

- Сервер ученика — Open Server Panel (`.osp/project.ini`): домен `learn-yarik.local`, Nginx, PHP 8.4.
  Корень сайта — корень репозитория, на это рассчитаны абсолютные редиректы вроде `/marlin/pdoBase/projectStart/`.
- MySQL: хост `MySQL-8.4` (имя модуля OSPanel), пользователь `root` без пароля. Базы: `base` (таблица `users`),
  `task_11` (таблица `text`), `task_12` (таблица `task_12`: `email`, `password`). Схем и миграций в репозитории
  нет, базы существуют только у ученика локально, поэтому страницы с PDO в другом окружении не запустятся.
- На маке наставника `php` — CLI из MAMP (8.2). Проверка синтаксиса: `php -l путь/к/файлу.php`.
  Скрипты без БД запускаются напрямую и печатают HTML в stdout: `php marlin/OOP/Car.php`.

## Структура

- `homeWork/` — ДЗ по HTML/CSS: сайт из нескольких страниц с общим меню и `style.css`, формы, hover.
  `homeWork/Readme.md` — список заданий от наставника: `+` сделано, `-` не сделано.
- `info/` — справочные примеры (`flex.html`, `hover.html` подключают `../homeWork/style.css`) и `справочник.md` —
  словарь терминов, который ведёт ученик.
- `php/` — первые скрипты: переменные, функции, if/else, массивы.
- `marlin/pdoBase/projectStart/` — CRUD пользователей на PDO: `index` → `create` → `store`, `show`, `edit` → `update`,
  `delete`. Подключение к БД скопировано в каждый файл. `$_GET`/`$_POST` передаются в `execute()` целиком, поэтому
  имена полей формы должны точно совпадать с плейсхолдерами в SQL.
- `marlin/20tasks/` — задачи курса Marlin на шаблоне SmartAdmin. `task_N.php` — самостоятельная страница с копией
  одного и того же `<head>`; `store11.php`, `store12.php` — обработчики форм задач 11 и 12. `css/`, `js/`, `img/`,
  `webfonts/` — файлы шаблона, их не редактируют.
- `marlin/OOP/` — классы `Person`, `Car` (и дочерний `SportCar`), `Book`. Каждый файл внизу сам создаёт объекты
  и печатает результат.
