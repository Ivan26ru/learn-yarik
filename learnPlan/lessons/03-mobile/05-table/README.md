# Занятие 5. Широкая таблица на узком экране

[Модуль 3. Вёрстка под телефон (от 360px)](../README.md) · занятие 5 из 5

**Где работаем:** эта папка: `table.html`.

Таблицу пользователей из `marlin/pdoBase/projectStart/index.php` на телефоне в 360px не втиснуть. Пусть таблица
листается вбок **внутри своего блока**, а вся страница стоит на месте.

```html
<div class="table-wrap">
    <table>...</table>
</div>
```

```css
.table-wrap {
    overflow-x: auto;
}
```

- [ ] Сделай в `table.html` таблицу машин на 7 столбцов и оберни её в `.table-wrap`.
- [ ] Проверь на 360px: листается только таблица.
