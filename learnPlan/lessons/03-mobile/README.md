# Модуль 3. Вёрстка под телефон (от 360px)

**Срок:** 2 недели, 5 занятий.
**Зачем:** большинство людей открывают сайты с телефона. Сайт, который на телефоне приходится двигать пальцем
вбок, выглядит сломанным. После этого модуля любая твоя страница будет хорошо смотреться и на узком телефоне
(360px), и на большом мониторе. Здесь же сверстаем карточки машин для «Гаража мечты».

Код каждого занятия — в папке этого занятия.

## Новые слова

- **Адаптивная вёрстка** — страница сама подстраивается под ширину экрана.
- **Viewport** — видимая область страницы в браузере.
- **Медиазапрос (`@media`)** — CSS, который включается только при определённой ширине экрана.
- **Горизонтальная прокрутка** — когда страница шире экрана и её приходится листать вбок. Это ошибка вёрстки.

## Главное правило

На ширине **360px**:

- страницу не нужно листать вбок;
- текст не обрезается и не налезает на соседей;
- все кнопки и ссылки видны целиком, по ним легко попасть пальцем.

Проверка: в Chrome нажми `F12` → значок телефона (Toggle device toolbar) → вверху выбери `Responsive` и впиши ширину `360`.
