# Занятие 3. Медиазапросы: меню на телефоне и на компьютере

[Модуль 3. Вёрстка под телефон (от 360px)](../README.md) · занятие 3 из 5

**Где работаем:** эта папка: `menu.html`. Стили можно начать с копии `styles.css` из `02-sizes`.

```css
.menu {
    display: flex;
    flex-direction: column; /* на телефоне — столбиком */
    gap: 8px;
}

@media (min-width: 768px) {
    .menu {
        flex-direction: row; /* на широком экране — в строку */
    }
}
```

Сначала пишем стили для телефона, потом через `@media (min-width: ...)` добавляем для больших экранов.
Это называется **mobile first** — «сначала телефон».
