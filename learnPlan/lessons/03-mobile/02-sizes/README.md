# Занятие 2. Гибкие размеры

[Модуль 3. Вёрстка под телефон (от 360px)](../README.md) · занятие 2 из 5

**Где работаем:** эта папка: `index.html`, `styles.css`, `img/`.

| Вместо              | Лучше                                    | Почему                           |
|---------------------|------------------------------------------|----------------------------------|
| `width: 800px`      | `max-width: 800px; width: 100%`          | на узком экране блок сожмётся    |
| картинка как есть   | `img { max-width: 100%; height: auto; }` | картинка не вылезет за экран     |
| `font-size: 14px` везде | `font-size: 1rem` / `1.25rem`        | размеры текста связаны между собой |
| `margin: 0 50px`    | `padding: 0 16px`                        | на телефоне хватает 16px по краям |

- [ ] Создай `styles.css` и `index.html`: заголовок, абзац, большая фотография твоей любимой
      машины (сохрани её в папку `img/` рядом), блок с текстом.
- [ ] Добейся, чтобы на 360px ничего не вылезало за экран.
