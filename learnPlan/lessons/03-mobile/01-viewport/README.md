**Где работаем:** правим страницы в `homeWork/`, заметки — в этой папке.

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

Без этой строки телефон делает вид, что он шириной 980px, и всё мелкое-мелкое.

- [ ] Открой на ширине 360px все страницы из `homeWork/`. Запиши в `notes.md` в этой папке, что сломано на каждой.
- [ ] Добавь meta viewport во все страницы `homeWork/`, где её нет.
