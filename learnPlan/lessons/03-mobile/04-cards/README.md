# Занятие 4. Карточки машин

[Модуль 3. Вёрстка под телефон (от 360px)](../README.md) · занятие 4 из 5

**Где работаем:** эта папка: `cars.html`.

```css
.cards {
    display: flex;
    flex-wrap: wrap;
    gap: 16px;
}

.card {
    flex: 1 1 100%;   /* телефон: одна карточка в ряд */
}

@media (min-width: 600px) {
    .card { flex-basis: calc(50% - 8px); }   /* две в ряд */
}

@media (min-width: 1000px) {
    .card { flex-basis: calc(33.333% - 11px); } /* три в ряд */
}
```

- [ ] Создай `cars.html` — «Мои машины мечты»: 6 карточек. В каждой — фото, марка и модель,
      год, цена, кнопка «Подробнее».
- [ ] Карточки: 1 в ряд на телефоне, 2 на планшете, 3 на компьютере.
- [ ] При наведении карточка немного поднимается и появляется тень (вспомни модуль 1).
- [ ] Проверка на длинное название: напиши в одной карточке `Mercedes-Benz GLE 63 S AMG Coupé Performance Edition`.
      Текст должен переноситься, а не вылезать.
