# Занятие 1. Кто угодно может сломать машину

[Модуль 2. ООП: инкапсуляция и порядок в классах](../README.md) · занятие 1 из 6

**Где работаем:** эта папка.

Скопируй `marlin/OOP/Car.php` в эту папку и допиши в конец копии:

```php
$yarikCar->price = -500;
$yarikCar->age = 9999;
echo $yarikCar->infoCar();
```

Машина с отрицательной ценой. PHP не возражает, потому что свойства `public` — их можно менять снаружи как угодно.

| Модификатор  | Кто может трогать                              |
|--------------|-----------------------------------------------|
| `public`     | все                                           |
| `private`    | только методы этого же класса                 |
| `protected`  | методы этого класса и его дочерних классов    |

- [ ] Сделай свойство `price` приватным: `private int $price;`. Запусти — что сказал PHP?
