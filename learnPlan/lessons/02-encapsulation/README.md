# Модуль 2. ООП: инкапсуляция и порядок в классах

**Срок:** 3 недели, 6 занятий.
**Зачем:** в справочнике уже записано: «инкапсуляция — спрятать код выполнения за названием функции или метода».
Это правда, но только половина. Вторая половина — **спрятать данные объекта**, чтобы никто не мог их испортить.
В этом модуле классы `Car`, `Person` и `Book` станут надёжными, а в конце появится класс `Garage` — заготовка
для итогового проекта.

Код каждого занятия — в папке этого занятия.

## Новые слова

- **Модификатор доступа** — слово перед свойством или методом: `public`, `private`, `protected`.
- **Геттер** — метод, который отдаёт значение свойства: `getPrice()`.
- **Сеттер** — метод, который меняет свойство и проверяет новое значение: `setPrice()`.
- **Ответственность класса** — то, за что класс отвечает. У хорошего класса она одна.
- **`require_once`** — подключить код из другого файла.
