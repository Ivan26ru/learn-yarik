# Занятие 2. Геттеры и сеттеры с проверкой

[Модуль 2. ООП: инкапсуляция и порядок в классах](../README.md) · занятие 2 из 6

**Где работаем:** эта папка. Сначала скопируй сюда `Car.php` из папки прошлого занятия (`01-private`) и продолжай в копии.

```php
public function getPrice(): int
{
    return $this->price;
}

public function setPrice(int $price): bool
{
    if ($price <= 0) {
        return false; // не меняем, сообщаем, что не получилось
    }
    $this->price = $price;
    return true;
}
```

- [ ] Сделай все свойства `Car` приватными и добавь геттеры.
- [ ] Сеттеры с проверками: цена больше 0; возраст от 0 до 100; цвет не пустая строка.
- [ ] Проверь: `var_dump($yarikCar->setPrice(-500));` должно показать `false`, а цена — остаться прежней.
