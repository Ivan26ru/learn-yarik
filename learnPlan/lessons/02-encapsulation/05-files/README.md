# Занятие 5. Каждый класс — в своём файле

[Модуль 2. ООП: инкапсуляция и порядок в классах](../README.md) · занятие 5 из 6

**Где работаем:** эта папка. Понадобятся классы из занятий 3 и 4 — скопируй их сюда.

Когда классов много, удобно держать каждый в отдельном файле, а работать с ними — в одном главном.
Например, `index.php` в этой папке:

```php
<?php
declare(strict_types=1);

require_once 'Car.php';
require_once 'SportCar.php';

$audi = new SportCar('Audi', 'RS6', 1, 1200000, 'black', 305);
echo $audi->infoCar();
```

- [ ] Разнеси `Car`, `SportCar`, `Person`, `Book` по отдельным файлам. В файлах классов не должно остаться
      `new` и `echo` — только сам класс.
- [ ] Создай `index.php`, который подключает классы и показывает, как ими пользоваться.
- [ ] `SportCar.php` пусть сам подключает `Car.php` через `require_once` — без родителя дочерний класс не работает.
