# Модуль 6. CRUD по-взрослому: безопасность и порядок

**Срок:** 2 недели, 5 занятий.
**Зачем:** список пользователей из `marlin/pdoBase/projectStart/` работает, но его легко сломать, а подключение
к базе скопировано в 6 файлов. Наведём порядок с помощью всего, что уже знаешь: функций, классов, сессий
и адаптивной вёрстки. Получится образец, по которому соберём «Гараж мечты».

## Новые слова

- **CRUD** — Create, Read, Update, Delete: создать, прочитать, изменить, удалить. Четыре действия почти любого сайта.
- **XSS** — когда кто-то вводит в форму HTML или JavaScript, и он срабатывает на странице у других людей.
- **Валидация** — проверка данных из формы до того, как сохранить их в базу.
- **Репозиторий** (в коде) — класс, который отвечает за работу с одной таблицей базы.
