- [ ] Создай `db.php`:

```php
<?php

{
    return new PDO('mysql:host=MySQL-8.4;dbname=base', 'root', '');
}
```

- [ ] Во всех файлах замени строку `new PDO(...)` на `require_once 'db.php';` и `$pdo = getPdo();`.
