# Занятие 4. Удаляем правильно

[Модуль 6. CRUD по-взрослому: безопасность и порядок](../README.md) · занятие 4 из 5

**Где работаем:** папка `app/` этого модуля (`learnPlan/lessons/06-crud/app/`) — одна программа, которую улучшаем от занятия к занятию.

Сейчас удаление — это обычная ссылка `delete.php?id=5`. Браузеры и программы иногда сами заранее открывают ссылки,
а значит, могут случайно удалить пользователя.

- [ ] Замени ссылку «Delete» маленькой формой:

```html
<form action="delete.php" method="post" onsubmit="return confirm('Точно удалить?');">
    <input type="hidden" name="id" value="<?php echo $user['id']; ?>">
    <button>Delete</button>
</form>
```

- [ ] `delete.php` берёт `id` из `$_POST`, а не из `$_GET`.
- [ ] Правило: **GET** — чтобы смотреть, **POST** — чтобы что-то менять.
