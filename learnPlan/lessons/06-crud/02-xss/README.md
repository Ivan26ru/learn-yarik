# Занятие 2. Ломаем свою страницу (и чиним)

[Модуль 6. CRUD по-взрослому: безопасность и порядок](../README.md) · занятие 2 из 5

**Где работаем:** папка `app/` этого модуля (`learnPlan/lessons/06-crud/app/`) — одна программа, которую улучшаем от занятия к занятию.

- [ ] Создай пользователя с именем `<h1 style="color:red">Взлом!</h1>`. Что случилось с таблицей?
- [ ] Вот так и работает XSS. Вместо безобидного заголовка злоумышленник мог бы вставить скрипт.
- [ ] Защита — `htmlspecialchars()`: превращает `<` и `>` в безопасный текст. Сделай короткую функцию в `db.php`
      (или в отдельном `helpers.php`):

```php
function e(?string $text): string
{
    return htmlspecialchars($text ?? '');
}
```

- [ ] Выводи **всё**, что пришло от пользователя, через `e()`: `<?php echo e($user['name']); ?>`.
- [ ] Проверь: «взломщик» теперь отображается как обычный текст.
