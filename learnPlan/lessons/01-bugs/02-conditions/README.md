# Занятие 2. Условие и текст должны говорить одно и то же

[Модуль 1. Закрываем хвосты и чиним ошибки](../README.md) · занятие 2 из 6

**Где работаем:** правим старый файл `php/ifelse.php`.

Открой `php/ifelse.php`. В каждом `if` прочитай условие вслух, а потом — что выводится в каждой ветке.

```php
if ($p >= 10) {
    echo $p . " больше или равно десяти";
} else {
    echo $p . " меньше десяти"; // в else попадают ВСЕ числа, для которых условие ложно
}
```

- [ ] Найди 4 места, где текст врёт (подсказка: строки 5, 23, 33, 41).
- [ ] Для каждого `if` поменяй значение переменной так, чтобы сработала **другая** ветка, и проверь, что текст правдивый.
- [ ] Закоммить.
