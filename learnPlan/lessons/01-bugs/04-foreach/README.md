# Занятие 4. Переменная, которая съела массив

[Модуль 1. Закрываем хвосты и чиним ошибки](../README.md) · занятие 4 из 6

**Где работаем:** правим старый файл `php/masiv.php`.

Открой `php/masiv.php`.

```php
foreach ($person as $person) { ... }
var_dump($person); // что тут теперь?
```

- [ ] Добавь `var_dump($person);` после первого `foreach`. Куда пропал массив?
- [ ] Переименуй массивы по смыслу: `$countries`, `$pets`, `$friends`. А переменная цикла — в единственном числе:
      `foreach ($countries as $country)`.
- [ ] Убери пробелы в начале ключей (`" strana2"` → `"strana2"`).
