# Занятие 3. Операторы сравнения (долг из `homeWork/Readme.md`)

[Модуль 1. Закрываем хвосты и чиним ошибки](../README.md) · занятие 3 из 6

**Где работаем:** новый файл `compare.php` — в этой папке.

| Оператор | Читаем как                          | Пример        |
|----------|-------------------------------------|---------------|
| `==`     | равно                               | `5 == 5`      |
| `!=`     | не равно                            | `5 != 3`      |
| `===`    | равно **и** того же типа            | `5 === "5"` → false |
| `!==`    | не равно или другой тип             | `5 !== "5"` → true  |
| `>` `<`  | больше, меньше                      | `10 > 3`      |
| `>=` `<=`| больше или равно, меньше или равно  | `18 >= 18`    |

- [ ] Создай в этой папке файл `compare.php`.
- [ ] Для каждого оператора — по 5 примеров из жизни: возраст для фильма, скорость машины, оценки, деньги на покупку.
      Пример: `$speed = 370; if ($speed > 300) { echo "Это гиперкар!"; }`.
- [ ] Хотя бы 2 примера, где `==` и `===` дают **разный** результат. Объясни наставнику почему.
- [ ] Поставь `+` у этого пункта в `homeWork/Readme.md`.
