# Занятие 5. Почему книга не изменилась

[Модуль 1. Закрываем хвосты и чиним ошибки](../README.md) · занятие 5 из 6

**Где работаем:** правим старые файлы `marlin/OOP/Book.php` и `marlin/OOP/Car.php`.

Открой `marlin/OOP/Book.php`. В конце файла:

```php
echo $book->updateStates('плохое');
```

Метод `updateStates` объявлен как `: void` — он **ничего не возвращает**. Значит, `echo` печатает пустоту.

- [ ] Убери `echo` перед `updateStates`, а после него снова выведи `getBook()`. Должно стать видно «было → стало».
- [ ] В `marlin/OOP/Car.php` метод `getYear()` считает `2026 - $this->age`. А в 2027 году? Замени `2026` на `date('Y')`
      — эта встроенная функция PHP возвращает текущий год.
- [ ] Ответь: чем метод `: void` отличается от метода `: string`? Когда перед вызовом нужен `echo`?
