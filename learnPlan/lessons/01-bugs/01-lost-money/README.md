# Занятие 1. Куда делись деньги?

[Модуль 1. Закрываем хвосты и чиним ошибки](../README.md) · занятие 1 из 6

**Где работаем:** правим старый файл `php/functions.php`.

## Как искать ошибку: 3 шага

1. **Что я ожидаю?** Посчитай или придумай ответ заранее, до запуска.
2. **Что получилось?** Запусти и посмотри.
3. **Где разошлось?** Проверяй переменные по очереди через `var_dump()`, пока не найдёшь место, где значение
   стало неправильным.

Если страница вообще не открывается, проверь синтаксис: `php -l php/ifelse.php`.

## Задание на занятии

Открой `php/functions.php` и найди функцию `vsegoDeneg`. Она должна сложить четыре суммы:
`600 + 512 + 903 + 493`.

- [ ] Посчитай на калькуляторе, сколько должно получиться.
- [ ] Запусти файл. Совпало? Если нет — найди, в чём ошибка, только глазами, без подсказок.
- [ ] Исправь и закоммить: «исправить vsegoDeneg».
- [ ] Переименуй параметры `$a, $b, $c, $d` в понятные: например, `$monday, $tuesday, $wednesday, $thursday`.
      Получилось бы так ошибиться с понятными именами?
