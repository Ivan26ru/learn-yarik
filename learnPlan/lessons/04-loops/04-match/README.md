# Занятие 4. `match`

[Модуль 4. Циклы, условия, функции массивов](../README.md) · занятие 4 из 6

**Где работаем:** эта папка: `match.php`.

```php
$grade = 5;
$text = match ($grade) {
    5 => 'отлично',
    4 => 'хорошо',
    3 => 'удовлетворительно',
    2, 1 => 'надо подтянуть',
};
echo $text;
```

- [ ] Номер дня недели → название (1 → «понедельник»).
- [ ] Марка машины → страна: `'BMW', 'Audi' => 'Германия'` и так далее, минимум 8 марок.
- [ ] Перепиши через `match` любые два `if` из `php/ifelse.php`. Стало короче?
