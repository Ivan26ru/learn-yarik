# Занятие 1. Цикл `for`

[Модуль 4. Циклы, условия, функции массивов](../README.md) · занятие 1 из 6

**Где работаем:** эта папка: `for.php`.

```php
for ($i = 1; $i <= 5; $i++) {
    echo "Круг номер " . $i . "<br>";
}
// 1) $i = 1 — с чего начинаем
// 2) $i <= 5 — пока это правда, крутимся
// 3) $i++ — после каждого круга прибавляем 1
```

- [ ] Выведи числа от 1 до 20.
- [ ] Выведи только чётные числа от 2 до 50. Подсказка: `$i += 2`.
- [ ] Обратный отсчёт старта гонки: 10, 9, 8 … 1, «Старт!».
- [ ] Таблица умножения на 7: `7 x 1 = 7` … `7 x 10 = 70`.
