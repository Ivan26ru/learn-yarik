# Занятие 5. Полезные функции для массивов

[Модуль 4. Циклы, условия, функции массивов](../README.md) · занятие 5 из 6

**Где работаем:** эта папка: `arrays.php`.

| Функция                  | Что делает                               |
|--------------------------|------------------------------------------|
| `count($a)`              | сколько элементов                        |
| `array_sum($a)`          | сумма чисел                              |
| `max($a)`, `min($a)`     | самое большое и самое маленькое          |
| `in_array('BMW', $a)`    | есть ли такой элемент                    |
| `sort($a)`, `rsort($a)`  | отсортировать по возрастанию / убыванию  |
| `array_keys($a)`         | список ключей                            |

```php
$speeds = ['Audi RS6' => 305, 'BMW X5 M' => 290, 'Lada Vesta' => 190];
foreach ($speeds as $car => $speed) {
    echo $car . ' — ' . $speed . ' км/ч<br>';
}
```
