# Занятие 3. И, или, не

[Модуль 4. Циклы, условия, функции массивов](../README.md) · занятие 3 из 6

**Где работаем:** эта папка: `logic.php`.

```php
$age = 11;
$money = 500;
if ($age >= 6 && $money >= 400) {
    echo "Можно в кино";
}
if ($age < 14 || $age > 65) {
    echo "Билет со скидкой";
}
if (!$isRaining) { ... }   // если НЕ идёт дождь
```

- [ ] «Можно ли сесть за руль?» Есть права **и** возраст от 18 лет.
- [ ] «Выходной?» Суббота **или** воскресенье **или** каникулы.
- [ ] Високосный год: делится на 4 и не делится на 100, **или** делится на 400. Проверь 2024, 1900, 2000, 2026.
      Подсказка: остаток от деления — `%`, например `2024 % 4` равно `0`.
