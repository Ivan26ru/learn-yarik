# Модуль 4. Циклы, условия, функции массивов

**Срок:** 2 недели, 6 занятий.
**Зачем:** `foreach` ты уже знаешь отлично. Но бывает, что нужно повторить что-то 10 раз, считать, пока не накопится
нужная сумма, или проверить сразу два условия. Этот модуль — набор маленьких задачек-головоломок, а в конце — игра.

Код каждого занятия — в папке этого занятия.

## Новые слова

- **Цикл `for`** — повторить действие заданное число раз.
- **Цикл `while`** — повторять, пока условие истинно.
- **Логические операторы** — `&&` (и), `||` (или), `!` (не).
- **`match`** — выбрать результат по значению: замена длинной цепочки `if`.
- **Бесконечный цикл** — цикл, который никогда не заканчивается. Это баг.
