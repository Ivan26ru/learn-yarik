Форма с тремя кнопками. Компьютер выбирает случайно через `rand(1, 3)`, PHP решает, кто победил.

```html
<form method="get">
    <button name="choice" value="rock">Камень</button>
    <button name="choice" value="scissors">Ножницы</button>
    <button name="choice" value="paper">Бумага</button>
</form>
```
