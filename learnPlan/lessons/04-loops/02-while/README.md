# Занятие 2. Цикл `while`

[Модуль 4. Циклы, условия, функции массивов](../README.md) · занятие 2 из 6

**Где работаем:** эта папка: `while.php`.

```php
$money = 0;
$week = 0;
while ($money < 15000) {   // копим на велосипед
    $money += 700;          // карманные деньги за неделю
    $week++;
}
echo "Накопим за " . $week . " недель";
```

- [ ] Запусти пример. Поменяй цену велосипеда и сумму в неделю.
- [ ] Машина едет 120 км/ч. Сколько часов пути нужно, чтобы проехать не меньше 1000 км? Реши через `while`.
- [ ] Что будет, если забыть `$money += 700;`? **Не запускай!** Сначала ответь, а потом проверь вместе с наставником.
