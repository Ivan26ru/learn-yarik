# Занятие 1. Переменная или массив?

[Модуль 5. Сессии, вход по паролю, загрузка файлов](../README.md) · занятие 1 из 9

**Где работаем:** задачи в `marlin/20tasks/`.

Сейчас в задачах 10, 13–17 одиночные надписи лежат в массиве из одного элемента и выводятся через `foreach`:

```php
$items = [['hint' => 'Кнопка была нажата: 0 раз', 'submit' => 'Submit']];
foreach ($items as $item) { echo $item['hint']; }
```

Массив нужен, когда элементов **много** и они **однотипные** (список машин, список картинок). Для одной надписи
хватит переменной — посмотри, как это уже исправлено в `task_11.php`.

- [ ] В задачах 13–17 замени такие массивы на обычные переменные (или просто напиши текст в HTML).
