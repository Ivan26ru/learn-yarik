# Занятие 5. Пароли храним в виде хеша

[Модуль 5. Сессии, вход по паролю, загрузка файлов](../README.md) · занятие 5 из 9

**Где работаем:** `marlin/20tasks/store12.php`.

Сейчас пароли в таблице `task_12` лежат как есть. Любой, кто увидит базу, увидит все пароли.

```php
$hash = password_hash($password, PASSWORD_DEFAULT); // при регистрации
password_verify($password, $hash);                  // при входе: true или false
```

- [ ] В `store12.php` сохраняй не пароль, а `password_hash(...)`.
- [ ] Зарегистрируй нового пользователя и посмотри в базе, что теперь лежит в поле `password`.
- [ ] Проверь: длины поля `password` в таблице хватает для хеша? Нужно не меньше 255 символов (`VARCHAR(255)`).
