# Занятие 7. Закрытая страница и выход (`task_16.php`)

[Модуль 5. Сессии, вход по паролю, загрузка файлов](../README.md) · занятие 7 из 9

**Где работаем:** `marlin/20tasks/task_16.php` и новый `logout.php`.

```php
session_start();
if (!isset($_SESSION['user'])) {
    header('Location: /marlin/20tasks/task_15.php');
    exit; // дальше страницу не показываем
}
```

- [ ] Страница приветствует пользователя по email из сессии.
- [ ] Кнопка «Выйти» ведёт на `logout.php`, который удаляет `$_SESSION['user']` и возвращает на вход.
- [ ] Проверь: после выхода `task_16.php` не открывается, даже если ввести адрес вручную.
