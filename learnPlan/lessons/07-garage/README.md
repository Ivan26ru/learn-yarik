# Модуль 7. Итоговый проект «Гараж мечты»

**Срок:** 6–8 недель.
**Зачем:** собрать в одном настоящем сайте всё, что изучено за полтора года. Это первый проект, который ты
придумываешь и строишь самостоятельно, от начала до конца.

Код проекта — в `learnPlan/lessons/07-garage/site/`, адрес: `http://learn-yarik.local/learnPlan/lessons/07-garage/site/`.
В папках этапов — только инструкции.

## Что должно получиться

- **Главная** — карточки машин: фото, марка и модель, год, цена. На телефоне в одну колонку, на компьютере в три.
- **Страница машины** — большое фото и все характеристики.
- **Вход для владельца гаража** — по email и паролю.
- **Админка** (только после входа) — добавить машину с фото, изменить, удалить.

Из чего это собрано:

| Часть проекта                         | Откуда умение                         |
|---------------------------------------|---------------------------------------|
| классы `Car`, `SportCar`, `Garage`    | модуль 2                              |
| карточки, меню, вид на телефоне, hover | модули 1 и 3                         |
| сортировка, поиск, условия            | модуль 4                              |
| вход, флеш-сообщения, загрузка фото   | модуль 5                              |
| `db.php`, `e()`, валидация, репозиторий | модуль 6                            |

## Чек-лист готовности

- [ ] Нет ошибок и предупреждений PHP ни на одной странице.
- [ ] Всё, что ввёл пользователь, выводится через `e()`.
- [ ] Пароль хранится только в виде хеша.
- [ ] Пустую или неправильную форму сохранить нельзя.
- [ ] Без входа в админку не попасть, даже набрав адрес вручную.
- [ ] Все страницы хорошо выглядят на 360px, 768px и 1280px.
- [ ] Нет отладочных `var_dump`.
- [ ] Каждый этап — отдельные коммиты с понятными сообщениями.
