**Где работаем:** сайт — в папке `site/` этого модуля (`learnPlan/lessons/07-garage/site/`).

- [ ] `index.php` — карточки машин из базы.
- [ ] `car.php?id=5` — страница одной машины. Нет такой машины — понятное сообщение, а не ошибка PHP.
- [ ] Общие куски (шапка с меню, подвал) — в отдельных файлах `header.php` и `footer.php`, подключаются через
      `require`. Меню больше не нужно копировать на каждую страницу, как в `homeWork`.
