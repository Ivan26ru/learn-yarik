# Этап 6. Админка (3–4 занятия)

[Модуль 7. Итоговый проект «Гараж мечты»](../README.md) · этап 6 из 8

**Где работаем:** сайт — в папке `site/` этого модуля (`learnPlan/lessons/07-garage/site/`).

- [ ] `admin/` открывается только после входа, иначе — редирект на `login.php`.
- [ ] Добавление машины с фото: валидация полей, проверка, что файл — картинка, сохранение в `uploads/`.
- [ ] Редактирование: можно поменять данные и, по желанию, фото.
- [ ] Удаление через POST с подтверждением; вместе с машиной удаляется и её фото.
- [ ] После каждого действия — флеш-сообщение («Машина добавлена»).
