# Модуль 8 (бонус). Первые шаги в JavaScript

**Когда:** после «Гаража мечты» или параллельно с ним, если захочется.
**Зачем:** PHP работает на сервере: нажимаешь кнопку — страница перезагружается. JavaScript работает прямо в браузере
и реагирует мгновенно: слайдеры, игры, анимации. С ним «Гараж мечты» станет живым.

Код каждого занятия — в папке этого занятия.

## Новые слова

- **JavaScript (JS)** — язык программирования, который выполняется в браузере.
- **Консоль** — место в браузере (`F12` → Console), куда JS пишет сообщения и ошибки.
- **Событие** — то, что произошло на странице: клик, ввод текста, наведение мыши.
- **DOM** — страница глазами JavaScript: дерево элементов, которые можно находить и менять.

## PHP и JS рядом

| Что               | PHP                          | JavaScript                         |
|-------------------|------------------------------|------------------------------------|
| переменная        | `$speed = 300;`              | `let speed = 300;`                 |
| вывод             | `echo 'Привет';`             | `console.log('Привет');`           |
| склеить строки    | `'Audi ' . $model`           | `'Audi ' + model`                  |
| массив            | `$cars = ['BMW', 'Audi'];`   | `let cars = ['BMW', 'Audi'];`      |
| перебор           | `foreach ($cars as $car)`    | `for (let car of cars)`            |
| функция           | `function sum($a, $b) {...}` | `function sum(a, b) {...}`         |

## Что дальше

Когда JavaScript станет привычным, можно выбрать направление вместе с наставником:

- **PHP-фреймворк** (например, Laravel) — в справочнике уже есть слово «фреймворк»: готовый набор того, что
  в «Гараже мечты» писалось вручную (вход, загрузка файлов, работа с базой).
- **Игры на JavaScript** — `canvas`, анимация, управление с клавиатуры.
- **Git поглубже** — ветки, чтобы пробовать новое, не ломая рабочую версию.
