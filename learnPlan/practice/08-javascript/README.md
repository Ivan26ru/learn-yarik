Решения клади в эту папку (`practice/08-javascript/`). Ошибки ищи в консоли: `F12` → Console.

## После занятия 1

*Привет из консоли*

- [ ] `tree.html`: ёлочка из звёздочек высотой 5 в консоли. Подсказка: `'*'.repeat(i)`.
- [ ] `sum.html`: сумма чисел от 1 до 100 в консоли.

## После занятия 2

*Кнопка-кликер*

- [ ] `plus-minus.html`: кнопки «+» и «−», число между ними. Число не может стать меньше 0 и больше 10.
- [ ] ⭐ На 10 нажатий — надпись «Ты супер-кликер!».

## После занятия 3

*Тёмная тема*

- [ ] `colors.html`: три кнопки — «Красный», «Зелёный», «Синий». Каждая красит фон страницы в свой цвет.

## После занятия 4

*Слайдер*

- [ ] ⭐ Слайдер сам листается каждые 3 секунды. Подсказка: `setInterval(function () { ... }, 3000)`.

## После занятия 5

*Угадай число*
