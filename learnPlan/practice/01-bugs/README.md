# Практика к модулю 1. Охота на баги

[Занятия модуля 1](../../lessons/01-bugs/README.md) · [Вся практика](../README.md)

В папке `bugs/` лежат маленькие программы, в каждой ровно одна ошибка. Вверху каждого файла написано,
что программа **должна** вывести. Чини прямо в этих файлах, а в конец допиши комментарий: в чём была ошибка.

```php
// Ошибка была: ...
```

Остальные решения клади в эту папку (`practice/01-bugs/`).

## После занятия 1

*Куда делись деньги?*

- [ ] `bugs/bug-1.php` — средняя оценка получается 10. Подсказка: вспомни из математики, что выполняется раньше —
      сложение или деление.
- [ ] `bugs/bug-2.php` — страница вообще не открывается. Прочитай сообщение об ошибке: на какой строке PHP
      заметил проблему? А на какой строке она на самом деле?
- [ ] Открой свой старый `php/vars.php` и переименуй 5 переменных с непонятными именами (`$oneyuslo`, `$belimoe`, …)
      так, чтобы через месяц было понятно, что в них лежит.

## После занятия 2

*Условие и текст должны говорить одно и то же*

- [ ] `bugs/bug-3.php` — Маше не досталась скидка, хотя должна была.
- [ ] `conditions.php`: придумай 3 своих условия про машины («Цена меньше миллиона — бюджетная»), обе ветки
      с правдивым текстом. Проверь каждое условие на двух значениях: чтобы сработала то одна, то другая ветка.

## После занятия 3

*Операторы сравнения*

- [ ] `compare-quiz.php`: для каждой строки **сначала** запиши ответ в комментарии (`// true` или `// false`),
      потом проверь через `var_dump`.

```php
var_dump(10 == "10");
var_dump(10 === "10");
var_dump(7 != 8);
var_dump("BMW" == "bmw");
var_dump(5 <= 5);
var_dump(3 > 3);
var_dump("10" === "10");
var_dump(true == 1);
var_dump(true === 1);
var_dump(0.1 + 0.2 == 0.3); // ⭐ сюрприз! Спроси у наставника, почему так
```

- [ ] Сколько ответов угадано с первого раза? Запиши результат в конце файла.
