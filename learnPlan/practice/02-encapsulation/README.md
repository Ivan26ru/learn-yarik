# Практика к модулю 2. Свои классы

[Занятия модуля 2](../../lessons/02-encapsulation/README.md) · [Вся практика](../README.md)

На занятиях мы чинили классы про машины, а здесь ты придумываешь свои. Главный герой практики — **тамагочи**,
виртуальный питомец, о котором надо заботиться. Решения клади в эту папку (`practice/02-encapsulation/`).

## После занятия 1

*Кто угодно может сломать машину*

- [ ] `Pet.php`: класс `Pet` с публичными свойствами `name`, `age`, `hunger` (голод от 0 до 10). Создай питомца
      и «сломай» его снаружи: `$pet->hunger = 500;`.
- [ ] Сделай свойство `hunger` приватным и посмотри, что скажет PHP. Как теперь узнать, насколько питомец голоден?

## После занятия 2

*Геттеры и сеттеры с проверкой*

- [ ] Добавь в `Pet` геттеры для всех свойств.
- [ ] Метод `feed(): void` — покормить: голод уменьшается на 3, но не ниже 0.
- [ ] Метод `play(): void` — поиграть: голод растёт на 2, но не выше 10.
- [ ] Метод `mood(): string` — настроение: голод до 3 — «доволен», до 7 — «скучает», больше — «очень голоден!».
- [ ] Покорми и поиграй несколько раз подряд, после каждого действия выводи настроение.
- [ ] ⭐ Пусть конструктор `Car` из занятия тоже пользуется сеттерами, а не пишет в свойства напрямую.

## После занятия 3

*`protected` и наследование*

- [ ] `animals.php`: класс `Animal` с защищённым свойством `name` и методом `speak(): string`, который возвращает
      «Я животное по имени …». Дочерние классы `Dog` и `Cat` переопределяют `speak()`: «Гав! Я …», «Мяу! Я …».
- [ ] В `Dog` используй `parent::speak()`, чтобы собака говорила и «Гав!», и то, что говорит любое животное.
- [ ] ⭐ Придумай второй дочерний класс для машины: `Truck` (грузовик) со свойством «грузоподъёмность».

## После занятия 4

*Одна ответственность*

- [ ] `team.php`: классы `Player` (имя, номер, позиция) и `Team` (название и приватный массив игроков).
      У `Team` методы `addPlayer(Player $player): void` и `showPlayers(): string`.
- [ ] Собери команду из 5 игроков и выведи её состав.
- [ ] Ответь в комментарии в конце файла: почему номер игрока хранится в `Player`, а не в `Team`?

## После занятия 5

*Каждый класс — в своём файле*

- [ ] Разнеси тамагочи по файлам: `Pet.php` — только класс, `tamagotchi.php` — подключает его через `require_once`
      и играет с питомцем.
- [ ] Сделай так же с `Player` и `Team`.

## После занятия 6

*Класс `Garage`*

- [ ] `library.php`: класс `Library` (библиотека) хранит объекты `Book`. Методы: добавить книгу, сколько книг,
      самая старая книга, общее количество страниц.
- [ ] ⭐ Метод `compare(Car $a, Car $b): string` в `Garage` — какая из двух машин новее. Похоже на
      `addMyFriend(Person $person)` из старого `Person`.
- [ ] ⭐ Тамагочи-приют: класс `Shelter` хранит несколько питомцев, метод `feedAll()` кормит всех сразу.
